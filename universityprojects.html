Campus Event Booking System 🎟️

Booking screen

Waitlist view

ENGG*1420 · Winter 2026

Object Oriented Programming course project — Java desktop application, built in a team

A Java-based desktop application that manages campus events, user registrations, bookings and waitlists.

Events, users and bookings are modelled as objects, so a full session pushes the next registration onto a waitlist, a cancellation frees that place for the person waiting, and the booking state is persisted between sessions rather than resetting on close.
